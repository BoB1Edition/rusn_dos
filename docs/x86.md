# x86 CPU — Instruction Reference

Processors: 8086–80386 (real mode, partial protected mode)

## Instruction Set Coverage

### Legend
- `[x]` — implemented
- `[~]` — partial/stub
- `[ ]` — not implemented (halts CPU)
