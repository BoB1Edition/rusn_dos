# Prompt: Рефакторинг кода

## Контекст
Требуется провести рефакторинг существующего кода для улучшения архитектуры, производительности или читаемости.

## Основные правила
1. Следовать стилю AGENTS.md (edition 2024, rustfmt, clippy-clean)
2. Не добавлять комментарии без необходимости
3. Использовать `Vec::with_capacity(n)` при известном размере
4. Не нарушать существующие трейты и API без крайней необходимости
5. Обновить все `.md` файлы, которые ссылаются на изменяемый код

## Типичные задачи
- Объединение дублирующегося кода (например, `mul_flags()` / `set_mul_overflow()`)
- Удаление мёртвого кода
- Переименование функций (например, `cbw()` → `cwde_or_cbw()`)
- Вынос общих констант

## Проверка
```bash
cargo build
cargo clippy
cargo test
```
