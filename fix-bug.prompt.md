# Prompt: Исправить ошибку в эмуляторе

## Контекст
Найдена ошибка в эмуляторе, описанная в ERRORS.md или выявленная тестированием.

## Процесс
1. Найти ERRORS.md или проанализировать проблему
2. Определить корневую причину
3. Реализовать исправление
4. Обновить ERRORS.md (отметить как исправленное или изменить статус)
5. Обновить TODO.md если relevant
6. Написать/обновить тест

## Проверка
```bash
cargo test
cargo clippy
RUST_LOG=debug cargo run Run <test_program>
```
