# topopcodes.md — 20 опкодов/команд/флагов для приоритетной реализации

Список составлен исходя из:
1. Частоты использования в реальных DOS-программах и играх
2. Текущих отсутствующих или сломанных опкодов
3. Критичности для запуска существующего софта

---

## 1. AAA (0x37) — ASCII Adjust after Addition
- **Статус:** отсутствует
- **Зачем:** BCD-арифметика, используется в старых DOS-программах для работы с десятичными числами
- **Что делает:** корректирует AL после сложения двух unpacked BCD чисел
- **Действие:** AL = AL + 6 если нужен перенос из младшей тетрады, AH += 1, CF/AF устанавливаются

## 2. AAS (0x3F) — ASCII Adjust after Subtraction
- **Статус:** отсутствует
- **Зачем:** парная к AAA, для вычитания BCD
- **Действие:** AL = AL - 6 если нужен заём, AH -= 1, CF/AF устанавливаются

## 3. BSF (0F BC) — Bit Scan Forward
- **Статус:** отсутствует
- **Зачем:** поиск первого установленного бита; используется в защищённом режиме, эмуляторах, компиляторах
- **Действие:** сканирует операнд от LSB к MSB, возвращает индекс первого бита=1, ZF=1 если бит не найден
- **CF/OF/PF/AF:** undefined

## 4. BSR (0F BD) — Bit Scan Reverse
- **Статус:** отсутствует
- **Зачем:** как BSF, но от MSB к LSB; используется для округления, MMX/SSE аналогов

## 5. INT 1Ch — User Timer Tick (исправить)
- **Статус:** заглушка (лог)
- **Зачем:** многие игры и демки используют INT 1Ch для синхронизации
- **Fix:** вызывать из INT 08h как цепочку, если вектор не 0xF000:0000

## 6. INT 09h — Keyboard Service (исправить)
- **Статус:** не читает scancode из порта 0x60
- **Зачем:** без этого не работает расширенная клавиатура и некоторые редакторы
- **Fix:** читать порт 0x60 и класть в BIOS-буфер

## 7. INT 10h / AH=02h — Set Cursor Position
- **Статус:** заглушка
- **Зачем:** вывод текста без курсора выглядит сломанным; игры и редакторы полагаются на позиционирование
- **Fix:** сохранять (DH, DL) как текущую позицию, использовать при телетайпном выводе

## 8. INT 10h / AH=0Eh — Teletype Output (исправить для Mode 13h)
- **Статус:** в Mode 13h не пишет в видеопамять
- **Зачем:** графические DOS-программы не увидят текст
- **Fix:** писать символ в видеопамять в текущей VGA-палитре

## 9. INT 16h / AH=00h — Read Key (исправить ожидание)
- **Статус:** не ждёт клавишу
- **Зачем:** почти все программы зависают или падают, если не дожидаются клавиши
- **Fix:** цикл ожидания, пока клавиатурный буфер не пуст

## 10. INT 21h / AH=01h — Read Char with Echo (исправить)
- **Статус:** блокирует эмулятор на stdin
- **Зачем:** любая программа, запрашивающая ввод, зависает
- **Fix:** читать из BIOS-буфера клавиатуры, а не из stdin

## 11. INT 21h / AH=06h — Direct Console I/O (исправить)
- **Статус:** DL=0xFF (проверка ввода) всегда возвращает "нет"
- **Зачем:** интерактивные программы не могут опрашивать клавиатуру
- **Fix:** проверять BIOS-буфер клавиатуры

## 12. INT 21h / AH=4B00h — EXEC (Load and Execute)
- **Статус:** отсутствует
- **Зачем:** запуск дочерних процессов (COMMAND.COM, редакторы из IDE, оверлеи)
- **Действие:** загрузить новый COM/EXE в память, передать управление, сохранить родительский PSP

## 13. INT 21h / AH=0Ah — Buffered Input
- **Статус:** отсутствует
- **Зачем:** ввод строк — базовый интерфейс всех текстовых программ
- **Действие:** читать строку с клавиатуры в буфер, обрабатывая Backspace, Enter

## 14. INT 21h / AH=1Ah — Set DTA
- **Статус:** отсутствует
- **Зачем:** FindFirst/FindNext сейчас всегда используют DS:0x0080
- **Fix:** сохранять сегмент:смещение DTA, читать из PSP+0x32/0x34

## 15. INT 21h / AH=39h — MKDIR (Create Directory)
- **Статус:** отсутствует
- **Зачем:** установщики и утилиты
- **Действие:** создать каталог по DS:DX пути

## 16. INT 21h / AH=3Ah — RMDIR (Remove Directory)
- **Статус:** отсутствует
- **Зачем:** обратная операция

## 17. INT 21h / AH=2Ah — Get System Date
- **Статус:** отсутствует
- **Зачем:** многие программы показывают/используют дату
- **Действие:** CX = year, DH = month, DL = day, AL = day_of_week

## 18. INT 21h / AH=2Ch — Get System Time
- **Статус:** отсутствует
- **Зачем:** многие программы показывают/используют время
- **Действие:** CH = hour, CL = min, DH = sec, DL = 1/100 sec

## 19. EIP — 32-битный IP (исправление регистра)
- **Статус:** ip: u16, eip закомментирован
- **Зачем:** без 32-bit IP не работают защищённый режим, Win16, DPMI, любая программа с сегментацией > 64KB
- **Действие:** заменить `ip: u16` на `eip: u32`, поправить fetch, CPUBus, и все инструкции, модифицирующие IP

## 20. 0x0F 0x01 /2 (LGDT) /3 (LIDT) — загрузка GDTR/IDTR из памяти
- **Статус:** работает (чтение базовых 24-bit адресов)
- **Зачем:** критично для перехода в защищённый режим
- **Но:** SGDT/SIDT (/0, /1) пишут заглушку вместо реальных GDTR/IDTR — это **надо исправить**
- **Fix:** в `/0` и `/1` писать `cpu.gdtr_limit` и `cpu.gdtr_base` (5 байт: u16 + u24 + padding), а не 0xFFFF/0

## Резюме по приоритетам

| Приоритет | Что исправить | Почему |
|-----------|---------------|--------|
| **P0** | EIP (32-bit), AAA, AAS | блокирует запуск многих программ |
| **P0** | INT 16h/00h (ожидание), INT 21h/01h | зависание на вводе |
| **P1** | INT 10h/AH=0Eh (13h), cursor | не видно вывод |
| **P1** | INT 21h/AH=06h, DTA, FindFirst | не работают файловые операции |
| **P2** | BSF, BSR, 0F 01 | для защищённого режима |
| **P2** | EXEC, MKDIR, RMDIR, дата/время | для совместимости с софтом |
| **P3** | SGDT/SIDT, INT 1Ch, INT 09h | полная совместимость |
