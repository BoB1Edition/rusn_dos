# PREALFA — Крейты и модули, предложенные для перевода в альфу

На данный момент предложений нет. Перевод в альфу будет возможен после:

1. Анализа необходимости многопоточности (видео, аудио, таймер — отдельные потоки)
2. Устранения всех `todo!()` и `unreachable!()` в целевом крейте/модуле
3. Полного покрытия комментариями для генерации `cargo doc`
4. Стабилизации API и обработки всех ошибок через `Result<T, Box<dyn Error>>`
5. Отсутствия `#![allow(dead_code)]`
