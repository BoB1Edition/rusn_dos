# Prompt: Добавить новую функцию DOS API

## Контекст
Нужно реализовать новую функцию INT 21h или другого прерывания DOS/BIOS.

## Требования
1. Добавить обработку в `crate/dos/src/interrupts/dos.rs` (или bios.rs/ems.rs)
2. Следовать шаблону существующих функций: извлечь параметры из регистров, выполнить операцию, установить результат
3. Использовать `set_carry_flag(sys, true/false)` для указания ошибки
4. Для ввода с клавиатуры: проверять `sys.machine.keyboard.pop_key()`, вызывать `sys.suspend_for_key(0x21)` если буфер пуст
5. Если новый вектор — добавить в dispatch в `interrupts/mod.rs`
6. При необходимости: установить IVT запись в `ivt.rs`

## Проверка
```bash
cargo build
cargo clippy
```
