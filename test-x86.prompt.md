# Prompt: Тестирование инструкций x86

## Контекст
Нужно написать или актуализировать модульные тесты для инструкций x86.

## Требования
1. Файл: `crate/x86/tests/<category>_test.rs`
2. Для каждой инструкции проверить:
   - Базовое выполнение (результат в регистре/памяти)
   - Корректность флагов (CF, PF, AF, ZF, SF, OF)
   - 8/16/32-bit варианты с префиксом 0x66
   - Граничные случаи (0, max, отрицательные числа)
   - ModRM register и memory режимы
3. Использовать `X86Cpu::new()` + `Motherboard::new(size)`
4. Установить регистры через `cpu.registers.set_*()`
5. Вызвать `instructions::<category>::<func>(&mut cpu, &mut machine)`
6. Проверить результат через `assert_eq!`

## Проверка
```bash
cargo test -p x86
```
